# Maritime Ship Detector YOLO11m-OBB v1

This directory contains public release metadata only. Model binaries are distributed
through the corresponding model-host repository, not through the source mirror.

The selected model is YOLO11m-OBB for a single `ship` class. It was selected from
the audit-fixed v2 development line at 1280 input pixels with seed 3 and geometric
augmentation. Reported metrics are project validation-split evidence; they are not
an independent test-set benchmark.

See `public_release_manifest.json` for artifact names, checksums, and limitations.
